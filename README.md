# 👕 LAS PILCHAS

Sitio web oficial de **LAS PILCHAS**, una marca de ropa con estilo urbano y moderno.

---

## 🚀 Descripción

Este proyecto es una página web simple creada con HTML y CSS, pensada para mostrar productos de ropa como:

- Remeras
- Buzos
- Gorras

Con un diseño minimalista, oscuro y enfocado en el estilo street.

---

## 🛠️ Tecnologías usadas

- HTML5
- CSS3

---

## 📂 Estructura del proyecto

/ (raíz)
│── index.html  
│── logo.png  
│── README.md  

---

## ▶️ Cómo usar

1. Descargar los archivos
2. Abrir `index.html` en tu navegador
3. ¡Listo! 🎉
